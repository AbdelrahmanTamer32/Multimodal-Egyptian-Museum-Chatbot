\# Multimodal AI Museum Guide Chatbot



Bachelor Graduation Project — German International University (GIU)



\## Overview



A multilingual multimodal AI museum guide chatbot designed to help users explore and learn about museum artifacts through natural language, voice, and images.



The system combines Retrieval-Augmented Generation (RAG), multilingual text retrieval, speech recognition, image retrieval, and a local Large Language Model (LLM).



\## Main Features



\- Text-based museum questions

\- Voice/audio questions using speech recognition

\- Image-based artifact identification

\- Multilingual support

\- Retrieval-Augmented Generation (RAG)

\- Refusal of unsupported museum-related queries

\- Text and image retrieval evaluation

\- Audio/ASR evaluation

\- Android/frontend interface



\## Technologies
